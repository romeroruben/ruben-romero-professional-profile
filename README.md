## Desarrollo local

No requiere instalación ni compilación. Se puede abrir `index.html` directamente o iniciar un servidor estático:

```bash
python3 -m http.server 8000
```

Luego visitar `http://localhost:8000`.

## Publicación

GitHub Pages publica la rama `main` desde la raíz del repositorio. El archivo `.nojekyll` evita procesamiento adicional y permite servir los archivos estáticos tal como están versionados.
